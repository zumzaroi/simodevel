# Your First SPICE Simulation: RC Low-Pass

## Overview
Create a first schematic, run transient and AC sweeps, and inspect waveforms to understand cutoff frequency behavior.

> Recommended workflow: complete this tutorial in order, verify each simulation result, then repeat with one parameter changed.

## Learning Checklist
- Install or open the required toolchain.
- Rebuild the core circuit or setup from scratch.
- Validate at least one measurable result.

## Lab Checklist Table
| Step | Action | Expected Result |
|------|--------|-----------------|
| 1 | Setup initial schematic or environment | Project opens without errors |
| 2 | Run baseline simulation or test | Stable waveform/output is visible |
| 3 | Change one key parameter | Observe predictable behavior change |
