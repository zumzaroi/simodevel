# Adjustable Bench Supply 1.25V-30V (LM317)

## Overview
A practical linear bench supply with adjustable output and thermal notes, focused on regulator stability and dropout behavior.

## Learning Objectives
- Understand the core ideas used in this Power project.
- Build and verify the circuit step by step.
- Practice troubleshooting with real measurements.

## Simulation and Validation
Run a basic simulation before hardware assembly. Check operating points and compare simulated behavior with measured values.
