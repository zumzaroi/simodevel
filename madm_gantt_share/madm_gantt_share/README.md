# MADM Gantt Share Package

This package is intended for local/offline sharing.

## Included
- `madm_gantt.html`
- `madm_year_data.js`
- `data/h_custom_fields.json`
- `data/test_data_2024.json`
- `data/test_data_2025.json`
- `data/admitere_2026_jud4.json`

## Run
Option A (quick): open `madm_gantt.html` directly in browser.

Option B (manual, recommended): run local server:

```bash
python3 -m http.server 8000
```

Open: `http://localhost:8000/madm_gantt.html`
